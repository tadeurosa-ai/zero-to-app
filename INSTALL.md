# Install

Download `zero-to-app-v<version>.zip` from the repository's **Releases** page. Check the SHA-256 listed there.

## Claude app (claude.ai / desktop)
1. Settings → Capabilities: turn on "Code execution and file creation".
2. Customize → Skills → "+" → "+ Create skill" → "Upload a skill" → choose the .zip.
3. Start a new conversation: "I want to build my first app" (or "quero tirar meu app do papel").

## Claude Code
Unzip into your skills folder so you get `~/.claude/skills/zero-to-app/SKILL.md` (or `.claude/skills/` inside a
project). Start a new session and say "I want to build my first app".

## ChatGPT desktop app / Codex
Not tested yet. The format follows the official docs (`~/.agents/skills/zero-to-app/`).
